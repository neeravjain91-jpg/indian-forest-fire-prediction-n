# India-Wide Forest Fire Occurrence Prediction (2018–2025)

Research-oriented framework for classifying **FIRMS fire-detection occurrence cells in India** from Suomi-NPP VIIRS observations and multi-timescale meteorological conditions.

## Final working model and web application

The repository contains the validated **HistGradientBoostingClassifier** model and a Flask web interface.

### Final model

The model uses 31 features:

- `grid_lat`, `grid_lon`, `hour`, `year`, `month`
- 6 one-day weather features
- 10 three-day weather features
- 10 seven-day weather features

Training protocol:

- Train: 2018–2022
- Validation: 2023
- Test: 2024–2025

The verified test results are:

- Accuracy: **70.01%**
- Precision: **68.47%**
- Recall: **74.21%**
- F1: **71.22%**
- ROC-AUC: **78.52%**
- PR-AUC: **78.32%**

### Run the web application

The application loads the trained model from:

`results/final_model/final_hgb_model.joblib`

and the saved metrics from:

`results/final_model/metrics.json`

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application from the repository root:

```bash
python application.py
```

Open:

```text
http://127.0.0.1:5000
```

The browser interface accepts the same 31 inputs used by the verified model and returns the predicted fire probability and class.

## Dataset

The validated dataset used by the final model is:

`data/processed/india_fire_weather_final.csv`

It contains:

- 131,000 observations
- 65,518 fire observations
- 65,482 non-fire observations
- 2018–2025 coverage
- 26,494 unique spatial cells
- 0 missing values in the final model features

The final model artifacts are generated by:

```bash
python train_final_model.py --data data/processed/india_fire_weather_final.csv --output results/final_model
```

This creates:

- `results/final_model/final_hgb_model.joblib`
- `results/final_model/metrics.json`
- `results/final_model/test_predictions.csv`
- `results/final_model/feature_importance.csv`

## Research contribution

This project does **not** claim novelty from the classifier itself. The research contribution is the India-wide dataset construction and controlled analysis of spatial, temporal and meteorological predictive signals, including multi-timescale weather features, ablation experiments and spatial generalization tests.

## Important limitation

The web application is a research/demo interface for the validated classification model. It is **not an operational emergency fire-warning system**.
